# LarpShop

## đừng commit vào branch `main` mà hãy tạo branch của mình và tạo pull request trước.

add mấy trang html mới vào:

```
resources/views
```

public frontend data thì mình bỏ vào đây:

```
public/css/
public/js/
```

khi mình làm mấy trang html thì mình lấy vào như sau:
```html
<html>
	<head>
		<link rel="stylesheet" href="css/example.css">
		<script src="js/example.js"></script>
	</head>
</html>
```

còn nhx thắc mắc khác thì hỏi trực tiếp pillotop depchai
